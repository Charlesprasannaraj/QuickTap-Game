# QuickTap — Reflex Game

A small browser game made with plain HTML, CSS and JavaScript.

## How to play
1. Open `index.html` in a browser.
2. Press **Start game**.
3. Tap the green target as many times as possible in 15 seconds.
4. Your best score is saved in your browser.

## Files
- `index.html` — game layout
- `style.css` — design and responsive styling
- `script.js` — timer, target movement, score and best-score storage

No install, build step or external JavaScript library required.
